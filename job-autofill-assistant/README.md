# 🎓 秋招网申助手

一个智能的Chrome扩展，帮助求职者自动填写秋招网申表单，支持多套简历资料管理和AI简历解析功能。

## ✨ 核心功能

### 已实现功能

- ✅ **智能表单识别** - 自动识别25+常见字段类型（中英文）
- ✅ **一键自动填充** - 点击悬浮按钮即可填写表单
- ✅ **多套资料管理** - 针对不同岗位使用不同简历
- ✅ **动态经历管理** - 支持添加任意数量的教育/工作/项目经历
- ✅ **技能标签管理** - 智能输入和推荐技能标签
- ✅ **简历文件上传** - 自动识别并上传简历PDF/Word文件
- ✅ **AI简历解析** - 粘贴简历文本，AI自动提取信息填入表单
- ✅ **数据导入导出** - 支持备份和恢复数据
- ✅ **填充结果高亮** - 已填充字段绿色高亮

## 📦 快速安装

### 1. 加载扩展

1. 打开Chrome浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `job-autofill-assistant` 文件夹

### 2. 配置资料

1. 点击扩展图标 → 点击"配置资料"
2. 填写基础信息（姓名、手机、邮箱等）
3. 添加教育/工作/项目经历
4. **（可选）配置AI设置，粘贴简历文本自动解析**
5. 点击"保存"

### 3. 开始使用

1. 访问任意招聘网站的网申页面
2. 点击扩展图标 → 点击"填充当前页面"
3. 检查并修改不正确的字段
4. 提交表单 ✅

## 🤖 AI简历解析（可选）

### 功能说明

粘贴简历文本，AI自动提取信息并填充到表单，无需手动输入！

**支持提取：** 基础信息、教育经历、工作经历、项目经历、技能

### 快速开始

1. **配置AI（首次使用）**
   - 打开配置页面，滚动到"AI设置"
   - 勾选"启用AI功能"
   - 选择"DeepSeek"（推荐，约0.001元/次）
   - 输入API Key（访问 https://platform.deepseek.com/ 获取）
   - 点击"保存"

2. **解析简历**
   - 复制你的简历内容
   - 粘贴到"简历内容"文本框
   - 点击"🤖 AI解析简历文本"
   - 等待10-30秒
   - 检查并完善信息
   - 点击"保存"

```
job-autofill-assistant/
├── manifest.json              # 扩展配置
├── popup/                     # 极简弹窗（360px）
│   ├── popup.html
│   ├── popup.css             # 深色主题
│   └── popup.js              # 核心操作
├── options/                   # 全屏配置页
│   ├── options.html          # 长表单设计
│   ├── options.css

│   └── resume-parser.js      # AI简历解析
└── docs/                      # 完整文档
```
