# 🚀 快速安装指南

## 📦 安装步骤（5分钟）

### 1. 准备扩展文件

确保你已经有 `job-autofill-assistant` 文件夹，包含以下文件：
```
job-autofill-assistant/
├── manifest.json
├── icons/
├── popup/
├── scripts/
└── styles/
```

### 2. 加载到Chrome浏览器

#### 方法一：开发者模式加载（推荐）

1. 打开Chrome浏览器
2. 在地址栏输入：`chrome://extensions/` 并回车
3. 开启右上角的 **"开发者模式"** 开关
4. 点击左上角 **"加载已解压的扩展程序"** 按钮
5. 选择 `job-autofill-assistant` 文件夹
6. 完成！扩展图标会出现在浏览器工具栏

#### 方法二：Edge浏览器

1. 打开Edge浏览器
2. 在地址栏输入：`edge://extensions/` 并回车
3. 开启左下角的 **"开发人员模式"** 开关
4. 点击 **"加载解压缩的扩展"** 按钮
5. 选择 `job-autofill-assistant` 文件夹
6. 完成！

### 3. 首次配置（必须）

**重要：首次使用前必须配置个人资料！**

1. 点击浏览器工具栏的扩展图标（紫色圆形）
2. 弹窗会显示配置界面

#### 填写基础信息（必填）
- 姓名、手机号、邮箱
- 性别、出生日期
- 所在地

#### 添加教育经历
1. 切换到"教育经历"标签
2. 点击"+ 添加"按钮
3. 填写学校、专业、学历等信息
4. 可以添加多条（本科、硕士等）

#### 添加工作经历
1. 切换到"工作经历"标签
2. 点击"+ 添加"按钮
3. 填写公司、职位、时间、描述

#### 添加项目经历
1. 切换到"项目经历"标签
2. 点击"+ 添加"按钮
3. 填写项目名称、角色、技术栈

#### 补充其他信息
1. 切换到"其他"标签
2. 添加技能标签（输入后按回车）
3. 填写自我介绍（可使用模板）
4. 上传简历文件（PDF或Word）

#### 保存配置
**点击底部的"💾 保存"按钮！**

## ✨ 开始使用

### 场景1：填写网申表单

1. 访问任意招聘网站的网申页面
2. **方式一**：点击页面右下角的紫色悬浮按钮
3. **方式二**：点击扩展图标，在弹窗中点击"✨ 填充当前页"
4. 等待填充完成（已填充字段会**绿色高亮**）
5. **检查并修改**不正确的字段
6. 提交表单

### 场景2：管理多套简历

如果你需要针对不同岗位使用不同简历：

1. 点击扩展图标打开弹窗
2. 点击顶部的 **➕** 按钮
3. 输入新资料名称（例如："前端岗位"、"算法岗位"）
4. 填写该资料的信息并保存
5. 使用下拉框随时切换不同资料

### 场景3：备份数据

定期备份，避免数据丢失：

1. 打开扩展弹窗
2. 切换到"设置"标签
3. 点击"📤 导出数据"按钮
4. 保存导出的JSON文件

需要恢复时：
1. 点击"📥 导入数据"按钮
2. 选择之前导出的JSON文件

## ⚠️ 常见问题

### 扩展无法加载？
- 确保已开启"开发者模式"
- 确认文件夹完整包含所有文件
- 尝试删除扩展后重新加载

### 点击悬浮按钮无反应？
- 确保已在弹窗中保存过资料
- 检查浏览器控制台是否有错误（F12）
- 刷新页面后重试

### 某些字段没有填充？
- 可能该字段在资料中未填写
- 可能字段识别规则未覆盖
- 建议手动补充未识别的字段

### 填充的数据不正确？
- 填充后会绿色高亮所有字段
- **务必逐一检查并手动修改**
- 这是辅助工具，不保证100%准确

## 🎯 最佳实践

1. **首次使用前完整配置**：填写所有信息才能发挥最大效果
2. **定期更新资料**：有新的实习或项目及时添加
3. **使用多套资料**：针对不同岗位准备不同版本
4. **定期备份**：每周导出一次数据
5. **人工检查**：自动填充后务必检查修改
