## 错误类型和解决方案

### ❌ API Key无效 (401/403错误)

**错误信息：**
- "401 Unauthorized"
- "403 Forbidden"
- "Invalid API Key"

**解决方法：**
1. 检查API Key是否正确复制
2. 确认没有多余空格
3. 检查API Key是否过期
4. 重新生成API Key

**各提供商API Key获取：**
- **DeepSeek**: https://platform.deepseek.com/api_keys
- **通义千问**: https://dashscope.console.aliyun.com/apiKey
- **智谱GLM**: https://open.bigmodel.cn/usercenter/apikeys
- **Kimi**: https://platform.moonshot.cn/console/api-keys

---

### ❌ 网络连接失败

**错误信息：**
- "fetch failed"
- "network error"
- "连接超时"

**解决方法：**
1. 检查网络连接
2. 尝试访问提供商官网
3. 检查防火墙设置
4. 使用VPN（如果需要）
5. 自定义API URL（使用代理）

---

### ❌ 模型不可用

**错误信息：**
- "model not found"
- "model not available"
- "invalid model"

**解决方法：**

**DeepSeek:**
- 默认模型：`deepseek-chat`
- 确认账号已充值

**通义千问:**
- 可用模型：`qwen-turbo`, `qwen-plus`, `qwen-max`
- 确认已开通DashScope服务

**智谱GLM:**
- 可用模型：`glm-4-flash` (最便宜), `glm-4`, `glm-4-plus`
- 确认已开通服务

**Kimi:**
- 可用模型：`moonshot-v1-8k`, `moonshot-v1-32k`, `moonshot-v1-128k`

---

### ❌ 额度不足

**错误信息：**
- "insufficient balance"
- "quota exceeded"
- "余额不足"

**解决方法：**
1. 登录提供商控制台
2. 检查账户余额
3. 充值
4. 最低充值：
   - DeepSeek: 10元
   - 通义千问: 按量计费
   - 智谱GLM: 按量计费
   - Kimi: 按量计费

---

### ❌ JSON解析失败

**错误信息：**
- "JSON解析失败"
- "数据格式不正确"
- "Unexpected token"

**原因：**
- AI返回的不是有效JSON
- AI理解错误

**解决方法：**
1. 检查简历内容是否清晰
2. 简化简历格式
3. 尝试不同的AI提供商
4. 手动修改提取的文本

## 调试步骤

### 1. 打开浏览器控制台

**Chrome:**
- 按 `F12` 或 `Ctrl+Shift+I`
- 切换到"Console"标签

### 2. 查看错误信息

执行AI解析时，控制台会显示详细错误：

```
[AI解析] 失败: DeepSeek API错误 (401): Invalid API Key
```

### 3. 根据错误类型解决

- `401/403`: API Key问题
- `network`: 网络问题
- `model`: 模型问题
- `JSON`: 解析问题

## 常见问题FAQ

### Q: 为什么测试连接成功，但解析失败？

**A:** 可能原因：
1. 简历内容太长（超过tokens限制）
2. 简历格式复杂（AI理解困难）
3. 网络不稳定

**解决：**
- 简化简历内容
- 分段解析
- 重试几次

---

### Q: 哪个AI提供商最好？

**A:** 推荐排序：

**最便宜：** 智谱GLM-4-flash (0.001元/次)  
**最稳定：** DeepSeek (0.001-0.005元/次)  
**最全面：** 通义千问 (0.002-0.01元/次)  

---

### Q: 解析结果不准确怎么办？

**A:**
1. AI不是100%准确
2. 务必检查并修改
3. 特别注意：日期、GPA、电话
4. 手动完善缺失信息

---

### Q: 支持扫描版PDF吗？

**A:** 不支持。扫描版PDF是图片，需要：
1. 使用OCR工具转换
2. 或手动复制粘贴文本

---

### Q: 可以离线使用吗？

**A:** 不可以。AI解析需要：
1. 网络连接
2. 调用在线API
3. 建议在有网络时配置好，之后填充不需要AI

## 性能优化建议

1. **简历文本尽量简洁**
   - 去掉多余空格
   - 删除表格边框符号
   - 保留核心信息

2. **分段解析**
   - 先解析基础信息
   - 再解析经历

3. **缓存结果**
   - 解析成功后立即保存
   - 避免重复解析

4. **选择合适模型**
   - 简单简历：GLM-4-flash
   - 复杂简历：DeepSeek/Kimi
