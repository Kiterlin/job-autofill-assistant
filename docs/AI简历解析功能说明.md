# 🤖 AI简历解析功能说明

## 功能概述

上传PDF或Word格式的简历，使用AI自动提取信息并填充到表单中，无需手动输入！

---

## ✨ 功能特点

- ✅ **支持格式**：PDF、DOC、DOCX
- ✅ **智能提取**：自动识别姓名、联系方式、教育经历、工作经历等
- ✅ **多AI支持**：DeepSeek、OpenAI、Gemini
- ✅ **成本低廉**：DeepSeek约0.001元/次
- ✅ **隐私安全**：文件不上传，仅提取文本后发送到AI

## 🚀 使用步骤

### 1. 配置AI设置

1. 打开扩展的**配置页面**（Options）
2. 滚动到底部的**"AI设置"**部分
3. 勾选"启用 AI 功能"
4. 选择AI提供商（推荐DeepSeek）
5. 输入API Key
6. 点击"保存"

### 2. 上传简历

1. 在"技能与简历"部分
2. 点击"📎 选择文件"
3. 选择你的简历（PDF或Word）
4. 等待上传完成

### 3. AI解析

1. 上传成功后，会出现"🤖 AI解析"按钮
2. 点击按钮
3. 等待10-30秒（根据简历长度）
4. 解析完成后，信息会自动填充到表单
5. **检查并完善信息**
6. 点击"保存"

## ⚠️ 注意事项

### 1. 数据准确性

- AI解析可能不是100%准确
- **务必检查并修改**不正确的信息
- 特别注意：日期格式、GPA、联系方式

### 2. 隐私安全

- 文件在浏览器本地提取文本
- 只有提取的文本会发送到AI API
- 不会上传完整的简历文件
- AI提供商会接收到文本内容（请查阅其隐私政策）

### 3. 成本控制

- 每次解析消耗少量tokens
- DeepSeek: 约0.001-0.005元/次
- OpenAI: 约0.01-0.05元/次
- 建议：使用DeepSeek最经济

### 4. 文件要求

- 格式：PDF、DOC、DOCX
- 大小：≤ 5MB
- 内容：可复制的文本（扫描版PDF不支持）

### 5. 解析时间

- 简单简历：10-15秒
- 复杂简历：20-30秒
- 网络延迟可能影响速度

## 🐛 常见问题

### Q: 点击"AI解析"没反应？

**可能原因：**
1. 未配置AI设置
2. API Key错误
3. 网络问题

**解决方法：**
1. 检查AI设置是否已启用
2. 验证API Key是否正确
3. 查看浏览器控制台错误

### Q: 解析结果不准确？

**可能原因：**
1. 简历格式复杂
2. 包含图片/表格
3. AI理解偏差

**解决方法：**
1. 手动修改不准确的字段
2. 尝试使用更好的AI模型（如GPT-4）
3. 简化简历格式

### Q: 解析失败？

**错误提示及解决：**

- **"AI_NOT_CONFIGURED"**
  → 请先配置AI设置

- **"EXTRACT_FAILED"**
  → 文件格式问题，尝试转换为PDF

- **"AI_PARSE_FAILED"**
  → API调用失败，检查API Key和网络

### Q: 支持扫描版PDF吗？

**不支持**

扫描版PDF是图片，无法直接提取文本。需要先用OCR工具转换。

### Q: 数据会被保存吗？

**会的**

解析后的数据会填充到表单，点击"保存"后会存储在本地。原始简历文件也会作为base64保存。

## 🔧 技术实现

### 文本提取
